# WorldFixer AI

**An open-source AI-powered personal coach for climate action and economic resilience.**

The world needs practical tools right now in 2026: track your carbon footprint, optimize personal finances amid uncertainty, get AI suggestions for green skills/jobs, and community impact.

## Features
- Carbon footprint tracker
- Budget & economic resilience advisor
- AI chat for personalized advice (using local models or Grok API)
- Green job/skill recommendations
- Local community action board (future)

Built with Next.js + Tailwind + local AI capabilities.

## Quick Start
```bash
git clone https://github.com/Jos1122yt33/worldfixer-ai.git
cd worldfixer-ai
npm install
npm run dev
```

Open in GitHub Codespaces for instant cloud dev!
